# Yapay Kodlama - Kişisel Yazılım, Teknoloji ve Donanım Blogu

Ankara Üniversitesi Bilgisayar Mühendisliği Bölümü **BLM2537 Ağ Tabanlı Programlamaya Giriş** dersi dönem projesi.

## Proje Hakkında
Bu web sitesi; yazılım geliştirme, yapay zekâ ve bilgisayar donanımları hakkında teknik makalelerin paylaşıldığı ve yönetildiği bir kişisel blog uygulamasıdır.

## Kullanılan Teknolojiler
- **HTML5:** Semantik sayfa yapısı (`header`, `nav`, `main`, `section`, `article`, `footer`), tablo ve form yapıları.
- **CSS3:** Özel renk değişkenleri (`:root`), Flexbox, CSS Grid ve Medya Sorguları (`@media`) ile mobil uyumlu tasarım.
- **JavaScript:** DOM manipülasyonu, form doğrulama ve `localStorage` ile makale ekleme, listeleme, güncelleme, silme (CRUD) işlemleri.
